## Export Mode

This directory contains the code for my new export mode and extension. 

### export
This directory contains the code for the new mode which displays the export button to the user. <br> The code is found within the /src/index.tsx file.

### export-extension
This directory contains the code for the export toolbar button and the logic for this button to extract the metadata and viewport image and then download them as a zip file. <br> The code is found within the /src/index.tsx file.

### download.tsx
This file contains the svg information for the export button.
